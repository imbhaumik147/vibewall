Features Built For Your New Tab

Every tool is crafted with vanilla HTML5, CSS3 glassmorphism, and instant local storage performance.

🖼️

Wallpaper Auto-Fit & Shading Engine

Scales high-res imagery using Auto-Fit (`100% 100%`) to guarantee full artwork visibility without top or bottom cropping. Includes cover fill, contain, overlay shading (0-90%), and real-time blur adjustments.

Auto-Fit No Clip Custom Uploads Blur Slider
🎯

Goal Tracker & Standalone Floating Cards

Create numerical targets with live progress ratios (`50 / 100 Completed`), gradient progress bars, instant `+1`/`-1` increment controls, and float any goal as an independent draggable desktop card.

Progress Ratios Draggable Cards
📝

Task Due Dates & Priority Badges

Manage deadlines with dynamic badges (🚨 Overdue, ⚡ Due Today, 📅 Due Tomorrow). Assign High, Medium, or Low priority badges and pop out floating task widgets.

Overdue Alerts Priority Badges
📐

Multiple Floating Sticky Notes

Click `+ Note` to spawn draggable floating note cards anywhere on your wallpaper. Auto-saving scratchpad with real-time word and character counters (`0w · 0c`) and drag-to-resize handles.

Word Count Multiple Notes
⏰

6 Horology Clock Typography Styles

Switch between 6 horology clock designs including Vintage Round Dial 🕰️ (Roman numerals, rotating hour/minute/second hands, date subdial), Minimal Clean, Brutalist, Editorial, Glass Pill, and Split Stack.

Analog Watch Dial 12h/24h Formats
🌤️

Worldwide Live Weather Forecast

Real-time atmospheric conditions powered by Open-Meteo. Type any global city (*Tokyo, London, New York, Paris*) with automatic geocoding and °C / °F switching.

City Lookup °C / °F Toggle
Developer & Local Setup

How To Install VibeWall Extension

View Repository on GitHub
1

Clone / Download

Clone repository or download ZIP from GitHub:
git clone https://github.com/imbhaumik147/vibewallExtension.git

2

Open Extensions

In Google Chrome or any Chromium browser, navigate to chrome://extensions in your address bar.

3

Enable Developer Mode

Toggle the Developer mode switch in the top-right corner of the Extensions page.

4

Load Unpacked

Click Load unpacked button and select the root folder of the extension directory. Open a New Tab to enjoy!
